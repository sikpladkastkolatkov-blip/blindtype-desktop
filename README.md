# BlindType Desktop

Самостоятельное Windows-приложение для тренировки слепой печати на русском языке.

## Требования
- Windows 10/11 (для сборки)
- Node.js LTS с npm

## Запуск в режиме разработки
Откройте PowerShell или терминал в папке проекта и выполните:
```bash
npm install
npm start
```

## Сборка установщика .exe
На Windows выполните:
```bash
npm run build
```
Готовый установщик появится в папке `dist` с именем `BlindType-Setup-1.0.0.exe`.

## Иконка
Поместите файл `icon.ico` в папку `build` и добавьте в раздел `win` файла `package.json` строку:
```json
"icon": "build/icon.ico"
```
Иконка должна быть в формате ICO (желательно 256×256).

## Примечание
Сборка Windows-установщика надёжнее всего выполняется на Windows. Для обычного запуска приложения нужен `npm install`, для установки на другой ПК передайте ему собранный файл из `dist`.
